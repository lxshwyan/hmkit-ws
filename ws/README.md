# @hmkit/ws

Extensible realtime communication toolkit for HarmonyOS and OpenHarmony.

It includes an API 12+ pure-ArkTS WebSocket client, configurable reconnect,
heartbeat and queue policies, typed codecs, Socket.IO 4 polling/WebSocket,
STOMP 1.2, MQTT 3.1.1/5, and opt-in IM persistence.

The core package does not require Socket.IO, STOMP, MQTT, IM persistence,
or native binaries at runtime unless the application explicitly uses those
features.

Documentation and examples:
https://github.com/lxshwyan/hmkit-ws
